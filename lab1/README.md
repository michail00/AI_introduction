## Структура папки lab1

апка data содержит данные, папка notebooks – ноутбук lab1.ipynb, файл requirements.txt – список библиотек.

## апуск на локальном компьютере

 папке lab1:

1. Создать окружение: python -m venv .venv
2. ключить окружение: .venv\Scripts\activate (macOS и Linux: source .venv/bin/activate)
3. становить библиотеки: pip install -r requirements.txt
4. ткрыть notebooks/lab1.ipynb в VS Code и выбрать ядро .venv
